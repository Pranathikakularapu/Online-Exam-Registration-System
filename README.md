# Online-Exam-Registration-System
An Online Exam Registration System is a web-based software project that automates traditional paper-based sign-ups. Its Software Requirements Specification (SRS) document defines how students sign up, select subjects, pay fees, and receive hall tickets, while allowing administrators to schedule tests and manage user data.
